# Latitat
## Theme:
You are a robot that wakes up in a tunnel that is flooded to half height.
<br>
You establish bases for different areas, craft items, traverse through mazes, survive monsters (some are blind some are deaf some are fast some are small some are large some are tanky), upgrade your robotic ability (boyancy cotnrol, speed, sight, night vision, heat vision and many more). GO through buildings to find documents, items and to fight rare monsters.
